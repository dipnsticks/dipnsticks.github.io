# DIP N’ STICKS — Brand Website

Pure static site: **no server, no install.** Double-click `index.html` to open it, or upload the whole folder to any static host (Netlify, Vercel, GitHub Pages, cPanel…). Pages: Home, Menu, About, Upcoming, Reviews, Policies, Location, 404. No ordering, cart, checkout, payments or admin.

## Reviews (no server needed)
- **Default:** reviews are validated and saved in the visitor's own browser (localStorage). They persist, but only that browser sees them.
- **Shared reviews for every visitor (free, no server of your own):** use a Google Sheet + Apps Script.
  1. Create a Google Sheet. Extensions → Apps Script → paste the code below → Deploy → New deployment → type *Web app* → Execute as *Me*, access *Anyone* → copy the web-app URL.
  2. Paste that URL into `js/config.js` (`reviewsUrl`). Done: reviews are stored in the sheet (delete a row to remove a review) and the page refreshes every 20 seconds.

```js
function sh(){const s=SpreadsheetApp.getActive();let t=s.getSheetByName('Reviews');if(!t){t=s.insertSheet('Reviews');t.appendRow(['date','name','rating','comment'])}return t}
function out(o){return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON)}
function doGet(){return out(sh().getDataRange().getValues().slice(1).map(x=>({date:x[0],name:x[1],rating:x[2],comment:x[3]})))}
function doPost(e){const d=JSON.parse(e.postData.contents),n=String(d.name||'').trim().slice(0,40),c=String(d.comment||'').trim().slice(0,600),r=Number(d.rating);
if(n.length<2||c.length<10||!(r>=1&&r<=5))return out({error:'invalid'});sh().appendRow([new Date().toISOString(),n,r,c]);return out({ok:true})}
```

## Editing content
HTML pages are generated by `build.py` (needs Python 3, only when you edit content): change the data at the top (phone, address, hours, menu, policies, social links, upcoming items) and run `python3 build.py`. Prices come only from your menu image. Social links and Upcoming items are hidden/empty until you add them. WhatsApp uses the shop phone number (`WA`).

## Notes
- Google Fonts and the Google Map need an internet connection; fonts have fallbacks.
- `404.html` uses root-relative paths, so it works on a hosted site (not when opened as a file).
- Food images are cropped from your menu at native resolution; replace files in `assets/images/menu/` (same names) with real photos for sharper results.
- Add `canonical`, `sitemap.xml` and a full `og:image` URL once the live domain is known.
